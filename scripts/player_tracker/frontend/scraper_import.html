ℹ️ Útmutató

FBref Import:

  • Teljes liga összes játékosának statisztikáit importálja
  • Selenium-alapú scraper (Chrome WebDriver szükséges)
  • Automatikusan létrehozza a ligát, csapatokat és játékosokat
  • Fuzzy matching párosítja a meglévő játékosokkal
  • Figyelem: Lassú lehet (sok adat), ~2-5 perc

SofaScore Import:

  • Egy konkrét meccs részletes statisztikáit importálja
  • TLS client-alapú scraper (gyors)
  • Meccs-szintű adatok (lineups, statistics)
  • Event ID megtalálása: SofaScore URL-ben (pl. sofascore.com/match/12345678)

Telepítés:

pip install -r requirements_scrapers.txt
